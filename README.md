# 📚 Course Recommendation System

**Author: Pranay M.**

Tool that suggests courses based on student interests and career goals.

## 🌟 Features

| Module | Description |
|--------|-------------|
| **Interest-Based Recommender** | Get courses by interests |
| **Career Path Advisor** | Plan career-aligned courses |
| **Skill Gap Analyzer** | Identify skill gaps to fill |
| **Prerequisite Mapper** | Map course prerequisites |
| **Course Load Balancer** | Balance semester workload |
| **Elective Explorer** | Explore elective options |
| **Minor/Concentration Planner** | Plan minors or concentrations |
| **Schedule Optimizer** | Optimize course schedules |
| **Graduation Path Planner** | Plan path to graduation |
| **Recommendation Summary** | Get complete recommendations |

## 🚀 Quick Start

```bash
ollama pull llama3.2 && ollama serve
pip install -r requirements.txt
python main.py
```
